# microscopy-image-standardisation
## Dataset Attribution

This project uses Dataset A: 186 digital images of MGG-stained blood smears from five patients with hereditary spherocytosis.

**Citation:**

Delgado-Ortet, M., Molina, A., Alférez, S., Rodellar, J., & Merino, A. (2020). *Dataset A: 186 digital images of MGG-stained blood smears from five patients with hereditary spherocytosis* (Version 1). Mendeley Data.

https://doi.org/10.17632/c37wnbbd3c.1

**Licence:** Creative Commons Attribution 4.0 International (CC BY 4.0).

The dataset is used for microscopy image standardisation experiments. Processed images and analysis results are generated as part of this project.
