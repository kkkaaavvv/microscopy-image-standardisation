# Week 2 Data Source



The blood-smear reference images used in Week 2 were obtained from:

Dataset A: MGG-stained peripheral blood smear images

Mendeley Data:
https://data.mendeley.com/datasets/c37wnbbd3c/1

DOI:
10.17632/c37wnbbd3c.1

The complete dataset is not included in this repository.
Only selected reference images used during the experiments are included.
